# Woxelz

A music-reactive live wallpaper for **macOS 14.2+** (built for macOS 26) and **Windows 10/11**.

Woxelz listens to whatever your computer is playing and renders an original real-time scene behind your desktop icons. When the music stops, it fades away and your normal wallpaper comes back.

## Download

Grab the latest build from **[Releases](https://github.com/vivan-j/woxelz/releases/latest)**:

- **macOS** — `Woxelz-macOS.zip` (universal: Apple silicon + Intel). Unzip and move `Woxelz.app` to Applications.
- **Windows** — `Woxelz-Windows-x64.zip`. Unzip and run `woxelz.exe`.

### First launch

- **macOS:** builds are self-signed rather than notarized, so the first time, right-click `Woxelz.app` → **Open** (or allow it under System Settings → Privacy & Security). macOS will then ask for **System Audio Recording** permission — that is how Woxelz hears your music; audio never leaves your Mac.
- **Windows:** SmartScreen may warn about an unrecognized app; choose **More info → Run anyway**.

## Using it

Everything lives in the menu bar (macOS) / notification area (Windows):

- **Show Wallpaper** — when music plays (default), when any sound plays, or always
- **Scenes** — 12 scenes across Flow, Contours, Sculptures, Space, Nature, Architecture and Journeys
- **Auto-Change** — a new scene for every song, or on a timer
- **Listen To** — system audio, any input device, or nothing
- **Reactivity**, **Quality**, **Frame Rate**, **Launch at Login**

Woxelz checks this page for new releases and asks before installing an update.
